### Additional minor findings (not in the first verbal report)

- `FileUtils.openFile`: operator precedence. In `... ?: if (ext.isNotEmpty()) MimeTypeMap…(ext) else null ?: when(...)`, the `when` fallback binds only to the `else` branch. For a known extension that `MimeTypeMap` doesn't recognise, the MIME type ends up `null`.
- `ImageEngine.shrinkImage`: "Keep EXIF" is silently ignored for PNG/WEBP output, and quality is ignored for PNG (the file may grow).
- `ImageEngine.enhanceDocumentScan`: transparent inputs come out with a black background. The output canvas is not filled white before the JPEG encode.
- `ImageEngine.extractColorPalette`: ignores alpha, so transparent areas count as black.
- `BitmapDecoder.isAnimated`: checks the extension on `uri.path`, which content URIs usually lack. It works anyway via the decode fallback, just slower.
- `VideoEngine.decodeToWav`: switches to the Main dispatcher for every output buffer to report progress. This is slow on long audio; throttle it as `calculateChecksums` does.
- `VideoEngine.videoToGif`: assumes `getScaledFrameAtTime` returns rotation-corrected frames. Portrait clips may come out stretched. [verify]
- `ToolJobService`: the notification permission is requested only once, ever. If denied, background "done" notifications never show, and there is no in-app hint.
- `AndroidManifest.xml`: `allowBackup="true"` with no backup rules. Harmless today, but review it before Play release.
